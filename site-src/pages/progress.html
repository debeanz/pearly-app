Progress reports

What changed, and why it matters for the games you play. For every single change, see the build history.

NewOctober 8, 2026

A new icon and a new site

A new icon

Pearly has a new icon: a pointer in pearl-white glass with a thin halo ring around it and a slot through its tail, on a graphite tile. It was picked from dozens of designs tried right on the Home Screen, then rebuilt with Liquid Composer, a web version of Apple's Icon Composer, so the ring and the pointer are real layers of iOS 26-style glass. The icon picker that helped choose it has done its job and is gone from Settings; Pearly has one icon now.

A new site

This site was redesigned around that icon, and it does more than before:

  • The compatibility list opens with an overview: how many games have been reported, how they rate, and the latest reports. You can filter 32-bit or 64-bit games, sort by best rated and switch to a list.
  • Each game's page adds up its reports: the frame rates people saw, the settings in Playable reports, the devices it was tried on and the problems that came up.
  • The build history lists every build with the change it brought.
  • A guide explains every setting, and the FAQ grew.
October 4–5, 2026

Sharper and steadier: MetalFX, DirectX 11 mode and Game Mode

MetalFX upscaling

DirectX 11 games can now render fewer pixels and let MetalFX, Apple's upscaler, fill the screen. The slider runs from Off up to whatever fills your device's screen at the resolution you picked, at most 2×. It takes effect when the game starts, and reports say when a game ran with it.

DirectX 11 mode for DirectX 12 games

Pearly draws with Direct3D 11 and 9, but plenty of DirectX 12 games ship a DirectX 11 path too. Pearly now looks for one, including Unreal Engine games and Unity games built with the Agility SDK, and starts them with -dx11. It's on by default and every such game has its own switch.

Game Mode and settings per game

Pearly now declares itself a game, so iOS can turn on Game Mode while you play. And every game's ··· menu has an Override switch: off, the game follows Settings; on, it keeps its own resolution, scaling, frame-rate cap, MetalFX and controls. Changing a setting from inside a game turns it on for you.

October 3–5, 2026

Controls, rebuilt

Controls got a full pass. Touch controls come in three kinds, Off, Xbox and Keyboard, and new installs start on the Xbox layout. A game's controls now live in one Controls section of its ··· menu, next to the settings for a physical controller: send it to the game as an Xbox controller (XInput), or have each button press a key you choose for games without controller support.

  • Touch controls hide while a controller is connected, and have an opacity slider.
  • Keyboard layouts come with presets and can be exported and imported.
  • A key bar above the iPhone keyboard adds Esc, Tab, Ctrl, Alt, the arrows and F1–F12.
  • A controller that connects in the middle of a game now reaches SDL and Unreal Engine games.
  • Where the game's own cursor is hidden, the touch trackpad moves the camera instead of hitting an invisible wall.
October 4, 2026

A better library

The Games tab learned to keep track: it shows the hours you've played each game, lets you favourite games and search and sort your library. Pixel-art games got screen scaling (Fit, Fill, Stretch or whole-number) and sharp pixels, in Settings or per game. A System status page shows what the app is up to, and replaced the old Containers tab.

October 3, 2026

Report Compatibility

Every game's ··· menu, the in-game toolbar and the crash alert now have Report Compatibility. Pick a rating, say what happened, and the report lands on the compatibility list with the build, device and settings the game ran on. The game's log goes along to the developer only: logs contain file paths from your phone, so they're never shown here.

The same week, games that open a launcher or a setup window first started working: those windows now appear over the game, along with the game's own message boxes.

32-bit games

Plenty of older games were only ever built for 32-bit Windows. Support for them came from 125hz's fork of Madeira, which runs each 32-bit game in a 4 GB address window of its own inside the app. Bringing that work into this fork took most of September.

  • Celeste, a .NET game running on the bundled Wine Mono, first ran at about 33 fps; fixing how Mono patches its own code got it to 60 fps in build 0.1.138.
  • Undertale, a 32-bit GameMaker game, runs.
  • Prince of Persia: The Two Thrones needed its launcher to pass: its install key, a second 32-bit window and the way Windows hands window procedures across the 32-bit bridge. It runs at 60 fps from build 0.1.149.
September 17, 2026

Settings for each game

Games got their own settings: a resolution that reaches the game itself rather than only the screen, a frame-rate cap, and the x86 memory-ordering switch, which keeps the strict ordering x86 games expect at some cost in speed. It's On by default; some games run faster with it Off.
