Build history

Pearly is built on GitHub every time the app changes, and the line beside each build is the change it brought. Versions are major.minor.patch: a huge update raises the first number, a medium one the second, and a small update or hotfix the third. Reports on the compatibility list name the version they were made with, so you can see when a game started working.
