About Pearly

What is Pearly?

An iOS app that runs Windows PC games on a non-jailbroken iPhone. It's a free, open-source research project under GPL-3.0.

Can I download it?

Not yet. It isn't released, so this site doesn't offer downloads. The build history and progress reports show what's happening.

How can an iPhone run Windows games at all?

Three translators work together inside one app. Wine answers the game's calls to Windows, FEX converts its x86 code to ARM64 while it runs, and DXMT turns its Direct3D graphics into Metal, which the iPhone's GPU draws. Even Wine's server runs as a thread inside the app, because an iOS app can't start processes of its own.

Is it an emulator?

Partly. FEX translates the game's x86 instructions to ARM64 as it runs, which is emulation. Wine and DXMT aren't: they re-implement Windows and Direct3D, so a game's calls go straight to iOS and Metal.

Setting up

Does it need a jailbreak?

No. It's an ordinary sideloaded app. The one special requirement is JIT, which StikDebug provides by attaching as a debugger.

Why JIT, and why isn't it on the App Store?

FEX writes new ARM64 code while the game runs, and iOS only lets an app do that while a debugger is attached. App Store apps can't have one, so Pearly is sideloaded and StikDebug attaches for it.

Which devices does it run on?

iPhone and iPad on iOS 17 or later. It's developed and tested mostly on recent iPhones, and newer chips run games faster. The compatibility list shows the devices each game was tried on.

Do I need a copy of Windows?

No. Wine stands in for Windows, so nothing from Microsoft is installed. Pearly ships no games either: you copy in games you own.

Games

Which games work?

The compatibility list has what players have reported. Direct3D 11 games are the best bet: Unity games like Untitled Goose Game run, and so do 32-bit games such as Celeste, Undertale and Prince of Persia: The Two Thrones.

What about DirectX 12, OpenGL and Vulkan?

Pearly draws with Direct3D 11 and Direct3D 9. Many DirectX 12 games also have a DirectX 11 mode, and Pearly starts them in it automatically. Games that only use DirectX 12, OpenGL or Vulkan don't run yet; OpenGL is planned.

Do 32-bit games run?

Yes. Each 32-bit game runs in a 4 GB address window of its own inside the app, an approach that came from 125hz's fork of Madeira.

What about games built on .NET?

Wine Mono is built in, so .NET games like Celeste start without installing anything.

My game opens a launcher first. Will it start?

Often, yes. A game's launcher, setup windows and message boxes appear over the game so you can click through them, and anything the launcher starts counts as the game.

Where do my saves go?

Inside the app, in its Wine prefix, the same place a Windows PC would keep them. They survive reinstalling Pearly.

Speed

How fast does it run?

It depends on the game. Untitled Goose Game holds 60 fps on an iPhone 15 Pro Max, while bigger 3D games are limited by the phone's GPU. Every game has its own resolution and frame-rate cap, and DirectX 11 games can use MetalFX upscaling.

Why does my iPhone get hot?

A PC game works the phone hard. After a few minutes of a heavy game it warms up, and iOS slows the chip down to cool it, which can lower the frame rate. A lower resolution or a 30 fps cap keeps it cooler.

What does MetalFX do?

It lets a DirectX 11 game draw fewer pixels and has Apple's MetalFX scale the picture up to fill the screen, at most 2×. You get most of the sharpness for less GPU work.

Controls

Can I play with a controller?

Yes. Bluetooth controllers reach games as an Xbox controller, and for games without controller support each button can send a key instead. A controller that connects mid-game reaches SDL and Unreal Engine games.

And without one?

Use the on-screen Xbox controller, or a keyboard layout you arrange yourself. The game picture works as a trackpad for the mouse, and a key bar above the keyboard adds Esc, Tab, Ctrl, Alt, the arrows and F1–F12.

Reports and privacy

A game crashed. What now?

Pearly offers to save the log or report the game right away. A report with its log attached is how games get fixed, and quitting and reopening Pearly before the next game avoids leftovers from the crash.

What does a report share?

Reports are public: your rating and notes, the device model, iOS and build versions, and the game's settings. The log goes only to the developer. It contains file paths from your phone, so it's never shown here.

How is a game's rating decided?

It's the rating most of the game's reports agree on; a tie goes to the better one. Each game's page shows every report, so you can see how the picture changed across builds.
