Guide

Using Pearly

What it needs, what every setting does, and what to do when a game misbehaves.

ON THIS PAGE Before you start The Games tab Settings for each game Controls Graphics Speed and heat Logs and reports What doesn't run yet

Before you start

Pearly isn't released yet, so there's no download here. This is what it will need.

Device
An iPhone or iPad on iOS 17 or later, no jailbreak. It's developed and tested mostly on recent iPhones; newer chips run games faster.
JIT
FEX writes ARM64 code while a game runs, which iOS only allows while a debugger is attached. StikDebug attaches one for you.
Installing
Pearly is sideloaded and signed with your Apple ID. With a free Apple ID, apps expire after 7 days and need reinstalling; your games, settings and saves stay, because the app's data survives a reinstall.
Games
Your own Windows games. Pearly ships no games, and nothing from Microsoft: Wine stands in for Windows.

The Games tab

Pearly opens on your games, shown with their Steam artwork in a row you move through like a console's. Pick a game to open its card: Play starts it, and the ··· button opens its menu with its settings, controls, Save Log and Report Compatibility. Quit a game and you're back in your library.

  • Star favourites, search, and sort your games; each card shows when you last played and for how long.
  • Games that start through a launcher still work: the launcher, setup windows and message boxes appear over the game so you can click through them, and anything the launcher starts counts as the game.
  • The Desktop tab is there for poking at Windows directly; most of the time you won't need it.

Settings for each game

Every setting lives in Settings for all games, and in each game's ··· menu for that game alone.

Override settings
Off: the game follows Settings. On: it keeps its own values for everything below. Changing a setting from inside a running game turns this on for you.
Resolution
The size the game renders at, passed to the game itself. Lower is faster and cooler.
Screen scaling
How the picture fills the screen: Fit, Fill, Stretch, or whole-number scaling.
Sharp pixels
Scales without smoothing, so pixel-art games stay crisp.
Frame rate cap
Holds the game to a steady rate, such as 30 or 60 fps. A steady 30 often feels better than a jumpy 45, and keeps the phone cooler.
MetalFX upscaling
DirectX 11 games only: render smaller and let MetalFX scale up, from Off to what fills your screen, at most 2×. It applies when the game starts.
DirectX 11 mode
Shown for DirectX 12 games that also ship a DirectX 11 path. On by default: the game starts with -dx11.
x86 memory-ordering
Keeps the strict memory ordering x86 games expect. On by default. Some games run faster with it Off; if a game crashes or hangs with it Off, turn it back On.
Controls
The game's touch layout and what a physical controller sends. See below.

Controls

Touch: Off
No on-screen controls; for games you play with a controller or keyboard.
Touch: Xbox
An on-screen Xbox controller, which games see as a real one. New installs start here.
Touch: Keyboard
Buttons and a stick that press the keys you choose, laid out where your thumbs rest. Layouts come with presets, have an opacity slider and can be exported and imported.
Trackpad
The game picture works as a trackpad for the mouse. When a game hides its own cursor, dragging moves the camera.
Physical controller
XInput sends it to the game as an Xbox controller. Send as keyboard makes each button press a key, for games without controller support. Touch controls hide while a controller is connected, and a controller that connects mid-game reaches SDL and Unreal Engine games.
Key bar
Esc, Tab, Ctrl, Alt, the arrows and F1–F12 above the iPhone keyboard.

Graphics

DXMT turns a game's Direct3D 11 calls into Metal, the iPhone's graphics API, and does the same for Direct3D 9 in 32-bit games. DirectX 12 games run when they ship a DirectX 11 mode, which Pearly starts them in automatically. Shaders are cached per game, so later launches have less to convert.

Runs
Direct3D 11

The main path. Most reported games use it.

Runs
Direct3D 9

For 32-bit games, such as Prince of Persia: The Two Thrones.

Through DX11
DirectX 12

Games with a DirectX 11 mode run in it; DirectX 12-only games don't.

Planned
OpenGL

Not yet. Bringing it in is the next big piece of work.

Not yet
Vulkan

Games that only draw with Vulkan don't run.

Speed and heat

A PC game works a phone hard. How fast a game runs depends mostly on how much it asks of the GPU: Untitled Goose Game holds 60 fps on an iPhone 15 Pro Max, while big 3D games are limited by the phone's graphics. If a game struggles:

  • Lower its resolution, and try MetalFX to win back sharpness.
  • Cap it at 30 fps: steadier, and the phone stays cooler.
  • After a few minutes of a heavy game the phone warms up and iOS slows the chip to cool it. A lower resolution or a frame cap delays that.
  • Try x86 memory-ordering Off, and turn it back On if the game gets unstable.

Pearly never changes a game's own configuration files to make it faster; every setting here works from the outside.

Logs and reports

Save Log
In a game's ··· menu and the in-game toolbar: keeps a dated copy of what happened, named after the game.
Report Compatibility
Pick a rating, tick any problems, give the frame rate and say what happened. The game's name, your device, iOS version, the build and the game's settings fill themselves in.
After a crash
Pearly offers to save the log or report the game right away. Quitting and reopening Pearly before the next game avoids leftovers from the crash.
What's public
Your rating, notes, device model, iOS and build versions, and the game's settings appear on the compatibility list. The log goes only to the developer: it contains file paths from your phone, so it's never shown.

What doesn't run yet

  • Games that only use DirectX 12, OpenGL or Vulkan.
  • Big, recent 3D games may start but run slowly: the phone's GPU is the limit.
  • Per-game quirks: check a game's page on the compatibility list before you copy it over, and add your own report when you've played it.
